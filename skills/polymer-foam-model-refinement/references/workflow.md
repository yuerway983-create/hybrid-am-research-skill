# 工作流与数据契约

本文件规定第一版离线分析的范围。有关研究事实和公式出处见 [来源与证据边界](sources.md)。

## 1. 确定观测量与范围

一次任务使用 `schema_version=foam-0.1`、`process=foaming-fdm`，`observable` 选择 `compression_modulus_MPa` 或 `compression_yield_strength_MPa`。所有响应都以 MPa 输入；对模量和强度分别建模，不能互换其归一化参考值或幂律参数。

`mode=offline_demo` 必须对应 `data_kind=synthetic_demo`；真实研究使用 `mode=research`，对应 `data_kind=measured` 或 `public_measured`。这是数据使用模式，与 `schema_version` 不同。CSV 的 `material_id`、`context_id`、`data_kind` 必须与任务一致；仅更改标签不能把合成数据变成实测数据。

记录聚合物及商品牌号、批次、宏观拓扑、单位胞尺寸、打印方向、加载方向、测试速率与响应提取方法。只能在可比范围内汇总；同一总密度并不保证泡孔形状或壁厚相同。材料、几何与测试信息未核实时，先标明缺口，不能据此声称得到通用材料定律。

所需致密材料参考响应写入 `base_property`，包括正的 `value`、`unit=MPa`、`source_ref` 和来源 `origin`；演示为 `synthetic_demo`，研究为 `user_calibration`。该值必须来自任务适用条件下的标定，未知时不能用论文值或假定常数补齐。`measurement_definition` 记录匹配的响应、测量方法、MPa 单位与来源；`fixed_conditions` 记录固定条件。

运行前声明两级孔结构与微观等效材料假设、`powerlaw` 的正系数与指数边界、`process_model` 的阶数及 Ridge 强度、`refinement` 的特征和理由、`acceptance` 的误差及退化容差。`scale_separation` 的壁厚／平均孔径比阈值必须有来源和审核状态；它是任务预声明条件，不是论文给出的普适常数。`dataset_file` 只能指向任务目录内的相对路径。

真实研究从[研究任务模板](../../../templates/foam-research/task.json)和[空 CSV 字段模板](../../../templates/foam-research/measurements.csv)另存新任务。模板中的 `null`、空对象及空列表保留未知或尚未声明的内容，需由用户测量和依据补齐后才能分析；默认观测量为模量，改为屈服强度时同步修改测量定义与参考性能。完整演示见[合成任务](../../../examples/foam-refinement-demo/task.json)，但不能将其材料参考值、拟合边界或验收阈值直接当作真实材料事实。

## 2. CSV 输入

| 字段 | 定义与单位 |
| --- | --- |
| `record_id` | 每条原始记录的唯一标识 |
| `sample_id` | 实物样品标识；同一样品的技术重复共用该值 |
| `condition_id` | 完整实验条件标识，不仅是温度标识 |
| `batch_id` | 制备或测试批次标识，用于防止跨分区泄漏 |
| `scale` | `micro`、`macro` 或 `hierarchical` |
| `temperature_C` | 打印温度，摄氏度 |
| `flow_ratio` | 无量纲切片出料倍率，例如 0.6 表示 60% |
| `total_relative_density` | 总体相对密度 `ρ̄`，以相应致密材料为参考 |
| `microscale_porosity_fraction` | `η`，微观孔隙体积占全部孔隙体积的份额 |
| `wall_thickness_um` | 实测壁厚，微米，不是名义设计值 |
| `mean_pore_diameter_um` | 实测平均泡孔直径，微米；保留测量方法及统计定义 |
| `response_MPa` | 该任务所选观测量的测量值，MPa |
| `material_id` | 与任务匹配的材料标识；牌号和已知配方记入固定条件 |
| `context_id` | 与任务匹配的加工和测试上下文标识；详细条件记入固定条件 |
| `data_kind` | 与任务匹配的 `synthetic_demo`、`measured` 或 `public_measured` |
| `partition` | `train` 或 `holdout`，运行前固定 |
| `source_ref` | 实测记录、数据集或来源的标识，可回溯到原记录 |

仅有名义壁厚或从示意图估算的泡孔值不能作为实测输入；缺失值不置零。所有数值列都必填：存在微观孔隙时平均孔径须为正，没有微观孔隙时该列按契约填写 0，表示不适用，不能表示未测量。需要的尺寸未测时先补测，不由大语言模型编造特征值。

检查有限数值、合法分区和标识一致性；`ρ̄` 在 `(0, 1]` 内、`η` 在 `[0, 1]` 内，温度高于绝对零度，出料倍率、响应与实际壁厚为正。相同 `condition_id` 必须具有相同 `scale`、`temperature_C` 与 `flow_ratio`；同条件不同样品的实测密度、孔隙份额、壁厚和孔径可以不同。相同样品的技术重复除响应外须保持数值输入及条件、批次、尺度和分区一致。`source_ref` 只能证明来源可回溯，不能把合成记录改称论文原始数据。

第一版要求 `micro` 和 `macro` 各至少 3 个训练条件，`hierarchical` 至少 4 个训练条件；三种尺度各至少 2 个留出条件。这些数量是程序下限，不能保证设计矩阵满秩或实验独立性。CSV 最大 10 MB、20000 条原始记录。

## 3. 密度换算与独立变量

使用论文 Eq. (3) 与 Eq. (4) 的定义：

```text
ρ̄ = ρa × ρμ
η = (1 − ρμ) × ρa / (1 − ρ̄)
ρa = ρ̄ + η × (1 − ρ̄)
ρμ = ρ̄ / ρa
```

`ρa` 是宏观结构的相对密度，`ρμ` 是构成壁材的微观相对密度。`η` 与局部微孔率 `1 − ρμ` 有不同分母；混用会改变模型含义。换算后检查两级密度在物理范围内并重构总密度。

`micro` 表示只有微观发泡孔隙，要求 `η = 1` 且非完全致密；`macro` 表示由致密壁材形成宏观孔隙，要求 `η = 0`；`hierarchical` 用于分级结构系列。对于 `ρ̄ = 1`，没有孔隙，`η` 在物理上未定义；程序要求规范值 0，两级密度均为 1，不把此约定用于辨认孔隙机制。致密材料参考响应另外由任务的 `base_property` 提供。

总密度、`η` 与两级密度存在确定代数关系。两级模型中只使用两项独立密度信息，不将总密度、`ρa`、`ρμ` 同时当作彼此独立的解释量。

## 4. 聚合、分区与训练

先按 `sample_id` 合并技术重复，保留原记录追踪关系；再使条件在拟合和误差汇总中等权。重复测量不是更多独立样品，样品多的条件也不应自动获得更大权重。

在运行前固定 `train` 与 `holdout`。同一样品、条件或批次不得跨分区，检查整个任务的数据。单尺度幂律分别在各自训练数据中做留一条件验证；分级模型交叉验证冻结由独立单尺度训练数据标定的原模型，每折只用其余分级训练条件拟合残差修正与标准化。工艺响应面的每折中心、标准化和回归也只在该折的微观训练数据内估计。第一版使用留一条件评估；它不等同于留一批次验证，若目标是泛化到新批次，应另行设计验证。

单尺度训练数据分别拟合微观与宏观幂律。用模量表示其组合形式：

```text
Ehier / Es = Cμ × Ca × ρμ^nμ × ρa^na
```

屈服强度使用同型关系但有独立的参考强度、系数和指数。脚本用条件等权、有界的对数最小二乘估计单尺度系数和指数，不能照搬论文 Table III 或声称复刻原作者的非线性拟合。报告单尺度条件数量、密度覆盖、参数、独立的交叉验证与留出误差；缺少任一级的可识别数据时，不宣称两级模型已标定。

训练 `micro` 数据还用于温度与出料倍率到微观相对密度的响应面：对非致密密度采用 logit 变换，`process_model.degree` 在运行前指定为 1 或 2，不截断密度端点来强行拟合。用微观训练条件的留一条件交叉验证与微观留出条件分别评估，密度误差为无量纲，并检查温度／出料倍率训练凸包覆盖。

该响应面只描述工艺到密度的经验关系。力学模型评估使用输入 CSV 的实测密度，不把预测密度代入力学模型评分。因此两部分分别通过检查，仍不代表温度／出料倍率到性能的端到端验证，也不证明温度对强度的独立因果作用或完整发泡动力学。

## 5. 预声明小幅修正

先写出观察、来源、候选机制、所需测量和被支持的范围，再冻结模型选项。`refinement.features` 从下列白名单选择 1～2 个不重复特征，并记录 `ridge_alpha`、`rationale`、`proposal_origin` 与 `source_refs`。脚本不执行大语言模型生成的任意表达式：

| 特征标识 | 拟检验的关系 | 解释边界 |
| --- | --- | --- |
| `porosity_partition_interaction` | `η × (1 − η)`，微观与其余孔隙份额的交互项 | 不额外乘总孔隙率，也不增加第三个独立密度变量 |
| `temperature_C` | 相同密度下加工温度可能对应泡孔形态差异 | 温度不是泡孔塌陷的直接测量 |
| `inverse_scale_ratio` | 平均泡孔直径相对于实际壁厚的比值 | 平均尺度比不能替代泡孔分布或图像证据 |

只有训练 `hierarchical` 数据可用于残差修正。在对数响应空间中对原始模型残差进行 Ridge 拟合，用训练集留一条件交叉验证选择模型；候选集合、特征数与响应面阶数在查看留出结果前冻结。

当前比较使用以下标识：

| 标识 | 实际实现 | 评估与选择 |
| --- | --- | --- |
| `baseline` | 单尺度训练数据标定后冻结的原始两级幂律 | 分级训练条件交叉验证及分级留出评估；参与选择 |
| `density_refinement` | 对原模型的对数残差，用 `log(ρμ)` 与 `log(ρa)` 做带截距的 Ridge 修正 | 分级训练条件交叉验证及分级留出评估；参与选择 |
| `host_proposed_refinement` | 对相同对数残差，用 `refinement.features` 做带截距的 Ridge 修正 | 分级训练条件交叉验证及分级留出评估；参与选择 |
| `constant_baseline_cv` | 每折仅用其余分级训练条件的等权平均响应作常数预测 | 仅有训练条件交叉验证，作比较参照；不参与模型选择 |

`density_refinement` 是普通密度修正对照，不是独立重拟合全部幂律常数。它的残差可改变组合系数与密度指数，但不能分别识别两个层级的新系数。两个修正模型共用预声明的 `refinement.ridge_alpha`。特征缺少变化、相关或条件不足时，模型标为不可用，不靠更改留出数据补救。

以可用候选的训练交叉验证 RMSE 最小值冻结 `selected_model`，再计算留出误差。不能因一个复杂模型在训练集拟合更好就宣布改进成立；同时检查留一条件误差、留出误差、参数可识别性及超范围使用。

任何模型选择都不使用 `holdout`。数值关口失败时，仍保留已经冻结的选择、原模型对照和失败原因；程序不会根据留出误差重新选择或回滚模型，不能将失败候选称为改进成立。查看留出数据后再改模型属于新的分析轮次，应明确记录其探索性质，并需要新的独立确认数据。

## 6. 结果与原因解释

运行入口：

```powershell
python scripts/foam_model.py run --task examples/foam-refinement-demo/task.json --out outputs/foam-demo-1
```

输出目录必须不存在，重复运行时使用新的 `--out` 目录；示例路径 `outputs/foam-demo-1` 只是可选的新目录。脚本先复制任务至 `input_task.json`，校验任务后复制 CSV 至 `input_measurements.csv`，后续读取冻结快照计算，不读取计算过程中变化的源文件。成功计算还生成 `model.json`、`result.json` 与中文 `report.md`；`analysis_used_frozen_input_snapshots=true` 标明分析使用快照。

成功结果的 `input_hashes` 记录实际输入快照 SHA-256；`source_hashes` 在模型与结果中记录 `foam_model.py` 和 `_core.py` 的代码哈希；`selection_sha256` 记录冻结选择；结果中的 `model_artifact_sha256` 记录模型文件哈希。输入或可识别性失败时 `status=blocked`、`prediction_performed=false`，生成失败 `result.json` 与 `report.md`，不生成模型；失败前已复制的一个或两个输入快照仍可能保留，不能把快照存在解释为校验或预测成功。

读取实际产物后汇报：数据来源与合成属性、分区及条件数量、密度换算、标定结果、交叉验证与留出比较、被选候选、有效范围和未解决的测量缺口。命令成功退出只表示完成计算，不表示数值关口通过；数值检查通过仍然是候选，模型文件状态固定为未实物确认。

先查看成功结果的 `decision_summary`：

- `mechanical_status` 为 `passed` 或 `failed`，对应顶层 `numerical_gates_passed`；`failed_numerical_checks` 列出失败的力学检查标识。
- `process_density_status` 为 `passed`、`failed` 或 `unavailable`，单独表示工艺密度响应面，不自动合并进力学关口。
- `scale_assumption_status` 保留审核状态；声明尺度比未通过时为 `ratio_failed`。即使标为已审核，平均孔径比仍不能证明连续体假设成立。
- `priority_actions` 给出对应缺口的优先补充事项；`physical_improvement_confirmed=false`，不是已确认的材料优化。

再核对 `numerical_checks`、`process_model` 和 `scale_separation` 的原始内容。顶层检查力学候选的误差、常数对照、原模型非退化及密度域等；工艺密度响应面的误差／域覆盖和声明尺度比另行报告，未合并进顶层关口。中文报告逐项列出力学检查、工艺误差与域覆盖，并声明未验证端到端预测链。额外特征的边际边界检查不等于完整联合覆盖。当前 `uncertainty=not_quantified`，不要附加未经标定的置信区间。

`numerical_checks.hierarchical_within_monoscale_calibration_domain` 要求全部分级训练与留出样品推导的 `ρμ`、`ρa` 分别位于对应单尺度训练密度区间，逐样品迁移检查记录在 `baseline_validation[scale].hierarchical_calibration_transfer`；超范围仍可生成诊断结果，但顶层数值关口为不通过。

原因解释采用“观察—证据—候选机制—需补测量”的链条。高温下泡孔塌陷、宏观 gyroid 幂律偏差和尺度分离不足来自原论文的特定条件，迁移到用户数据时均需核对。单位胞尺寸、壁厚、泡孔分布、批次和测试条件可能混杂；只凭相关性或残差系数不能认定机制。

限定范围内改变输入所得的预测变化称为“模型敏感性”。力学情景同时检查分级总密度／孔隙份额训练凸包、微／宏单尺度标定密度区间与所选修正特征的边际范围；工艺密度情景检查温度／出料倍率训练凸包。`declared_training_range` 仅为原始训练极值，实际扫描点支持范围见 `sampled_supported_range`，不能混用。

先检查每项 `available` 与 `sampled_points_count`：少于两个不同受支持点时 `available=false`，只能说明暂不可比较，不解释为零效应。有足够支持点时，`direction` 为 `increasing`、`decreasing`、`non_monotonic` 或 `flat`，按有限扫描预测的数值容差区分；`flat` 不是统计上已证明无影响。一起汇报固定参考 `fixed_reference`、支持点数、两端输入／预测 `endpoint_predictions` 和响应跨度；两端预测不代表区间极值，特别是非单调关系。

方向只描述固定参考下的受支持扫描点，不保证两个端点之间每处都有支持或同样趋势，不代表因果效应、可靠性区间或可直接执行的设备建议。具体建议应注明适用范围与待核对测量，例如“在本批次已测范围内，比较同密度不同温度样品的泡孔形状与压缩响应”，不能写成保证性能提升的设备设定。

## 7. 下一轮实验与停止边界

本版本没有自动实验规划器、设备指令或确认实验导入闭环。需要下一轮实验建议时，先核对可用预算、基准条件、温度和出料倍率允许范围、候选网格、样品与批次数量，再给出可审查的测量建议。未知物理参数保持未知；如果建议依赖尚缺的尺寸或泡孔统计，优先补测。

只从压缩模量或屈服强度不能推出完整吸能曲线、疲劳或循环寿命、降解行为及临床用途。没有新实物确认实验时，使用“现有数据支持的候选”或“合成流程演示”，不写“已实物验证”“完整闭环”或“新发现”。
