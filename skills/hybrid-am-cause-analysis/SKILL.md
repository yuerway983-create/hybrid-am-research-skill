# 混合打印原因分析与参数调整

## 使用目标与状态

将“观察到什么 → 哪些原因有依据 → 怎样区分 → 下一轮测什么／调什么”连成可检查的决策。
当前为文件型 LLM 宿主可读取的子 Skill；尚未注册到原仓库自动主控。读取 [references/integration.md](references/integration.md) 中的接入约定、输出字段和预算规则，再开始分析。

## 读取输入

- 原任务中的观测量、材料对、`context_id`、固定条件、因素范围与步长、基准参数、目标及预算。
- 对应会话已经生成的 `data_check.json`、`calibration.json`、`plan.json`；回传后还可读取 `feedback.json`、`comparison.json`、实际设置和测量。文件不存在时将该部分记为缺失。
- 授权使用的证据包及实际可读的原文位置。证据包声明已读全文，不等于本次宿主已核实所有段落；引用时保留访问层级。

记录输入文件、版本或哈希，以及宿主模型标识（若可取得）。分清以下阶段：实验前没有异常记录时检查假设和设计风险；已有测量时分析现象；回传后分析实际设置与冻结模型的偏差。
缺失信息只限制依赖它的结论：有现象但无目标值时继续排查，有目标但无异常时做设计风险分析，缺模型仍可提出区分实验，缺边界仍可给方向。仅在现象和目标均无法确定时，先列出最小输入。每个缺口注明它阻止哪项结论／建议。

## 分析步骤

1. **对齐目标。** 明确这次是排查原因、补标定，还是接近目标值。以任务的目标误差／明确的评价指标判断方向；“线宽越小”只有在目标确实要求时才算改善。多个目标有冲突但优先级未声明时，给取舍，不自行加权。
2. **描述现象并查数据。** 引用记录，核对实际条件、单位、测量定义、技术重复和批次。优先检查能用现有记录排除的问题。几何线宽与浓度 sigma、等待时间与曝光时间分别处理。
3. **区分事实与解释。** 将证据标为本工况观察、已有模型输出、适用的文献机制或待检验假设。残差模式、时间先后和相关性不能单独证明原因；材料／设备不匹配的文献只能作参考。
4. **排序候选原因。** 先看能否解释主要现象，再看证据支持、反证和工况匹配。必要时保留少量替代解释。说明为何先检查某项；检查成本影响行动顺序，不代表原因更可能。无需凑固定数量或自报原因概率。
5. **设计区分检查。** 为优先假设说明改变的因素、保持的条件、要测的响应，以及什么结果支持或削弱它。阈值有依据才给数值，否则给可观察的趋势。不能区分两个原因的检查不得宣称能确认根因。
6. **选择建议等级并分配预算。** 按下表输出；试验建议绑定假设或目标，计入下一轮总预算并遵守原规划器的基准保留规则。优先提出足以推进判断的一组检查，不同时改多个未分离的因素。
7. **核对与记录。** 核对引用、上下文、单位、边界、网格、固定条件和预算。无法完成的检查标为未核验；保存简短依据、建议与信息缺口，既有数据／模型／计划保持原版本。

| 建议等级 | 何时使用 | 可以输出什么 |
|---|---|---|
| `direction_only` | 缺范围、步长或必要工况，或没有可用诊断名额且不能复用已有试验 | 调整方向、记录核查、取舍及继续推进所需的信息；不提出新数字点位 |
| `diagnostic_trial` | 有因素范围、网格和可用预算，或可对应已有试验，但机制／模型尚待检验 | 范围内的区分或标定候选；不附目标达成预测 |
| `target_candidate` | 匹配的数值模型关口通过，候选位于验证域，约束与预算已核验 | 以已有工具结果为依据的目标候选；仍需外部实验确认 |

剩余预算为零时仍继续原因排查和现有记录核查，使用 `direction_only`／`report_only`。可以引用原任务的基准参数说明预算，但不得将其伪装成新建议或额外诊断点。

## 建议的依据与限制

- 每项主要结论提供文件字段／记录编号或文献来源及位置；不能核实的引用记为缺口。文献支持机制存在，不等于支持本工况的具体原因。
- `bounds_review_status=needs_review` 时，数字只能标为待审候选。任务范围内不等于设备或材料已经验证可行。
- 标定关口失败或训练范围不匹配时，使用 `diagnostic_trial` 或 `direction_only`。给具体标定候选不要求模型先通过，但不得用失败模型排序为目标最优。
- 新增压力、温度、曝光量等因素须有允许范围、步长与来源。原任务未声明这些因素时，可提出补充测量或另建任务，不能暗中改变 `fixed_conditions`。
- 浓度 sigma 模型中的非负方差增长关系用于检查该模型假设；不据此要求所有几何线宽必须单调增加。
- 没有堵头记录时只能提出堵头假设；没有相应材料模型和测量时，不给堵头概率、固化程度、界面强度、疲劳寿命或场分布数值。
- 无法判断时输出信息缺口及最有区分力的下一项检查。多个 LLM 意见一致不是独立物理验证。
- 原仓库的冻结评分、先比较后更新和新独立确认继续适用。回传解释不是预先预测；已经用来修改假设的结果不能再作独立确认。

## 输出

以中文输出可供研究者审核的简短分析，并保存可检查的摘要（不保存私人思考过程）：

- **现象与依据**：观测量、工况、记录和来源；
- **候选原因**：支持证据、反证、优先检查理由；
- **区分检查**：改什么、保持什么、测什么，以及哪些结果支持／削弱假设；
- **参数建议**：建议等级、目标／假设、方向或候选值、取舍、约束检查和预算占用；
- **下一步**：进入现有候选实验、补标定，或等待外部测量。

生成结构化输出时读取 [schemas/analysis.schema.json](schemas/analysis.schema.json)，使用参考文件中的预算和跨字段检查规则。格式检查只验证结构；原因与建议仍需证据核查。
分析报告可供现有规划阶段参考，但不是原运行时已经执行的实验方案，也不是设备指令。
