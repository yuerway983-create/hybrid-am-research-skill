# Axiom Research v1.1.3

Release notes. The original `RELEASE_DRAFT.md` filename is retained so existing package links remain valid.

A modular LLM-assisted research framework connecting scientific evidence, numerical modelling and experimental feedback through reusable Skills.

## What is included

- A host-directed VPP–DIW track-width / diffusion workflow, including numerical calibration, bounded proposals, frozen-prediction comparison and validated model updates.
- An independent hierarchical-polymer-foam modelling and refinement module.
- Host-read cause analysis, evidence and reusable Skill instructions, example data, research templates, tests and historical run records.
- English and Chinese project overviews, a bilingual static page, editable top-down workflow diagrams with local SVG exports, and a directory-by-directory package guide.
