围绕牛津大学 Reece Oosterbeek 团队的发泡 FDM 研究，从关键因素与测量数据出发，用两级简化模型分析孔结构与压缩性能，并提出可检验的改进方向。

与 Reece 研究的衔接

研究依据是 Sevcenco、Walters、Siviour 与 Oosterbeek 关于发泡熔融沉积成型分级多孔超材料的论文。它把打印形成的宏观孔结构与材料内部的微观泡孔联系起来，建立两级密度与力学性能模型。

本项目在这一研究基础上，加入 LLM 辅助的证据整理、候选机制解释，以及可复算的模型比较和有限修正。这里的 LLM 分析与软件实现属于本项目的扩展。

这个步骤可以做什么

提取关键因素

整理温度、出料倍率、总相对密度、微观孔隙份额及实测几何；核对出处、单位与缺失信息。

运行简化计算

换算微观／宏观相对密度，标定两级幂律；每次分析小应变压缩模量或初始压缩屈服强度中的一种。

比较与修正模型

比较原始模型、普通密度残差修正及最多两个预先声明的宿主修正特征；训练条件交叉验证后冻结，再评分留出数据。

解释结果与建议

输出误差、受支持范围内的敏感性和优先补测项。LLM 结合证据给出原因假设与参数方向，具体实验由研究者审核。

从已有数据到下一步实验

  1. 定义研究问题：固定材料、拓扑、测试条件与目标观测量，整理文献和真实测量。
  2. 简化计算与标定：核对两级密度，拟合原始模型；温度／出料倍率到内部密度的经验关系单独评估。
  3. 比较模型：预声明候选修正，完成训练分组验证与冻结后的留出评分，检查适用范围。
  4. 形成实验建议：读取中文报告，结合预算与设备范围审核建议；打印、测试和新数据回传由研究者完成。
“虚拟仿真”在这里指轻量模型计算与有限参数扫描。

当前未实现完整发泡过程仿真、端到端工艺到性能预测或自动实验规划。LLM 负责证据与解释，数值由脚本计算。

输入与准备输出与用途
同材料与测试条件的基体、单尺度及分级结构数据两级模型、误差与适用范围检查

先运行一个合成案例

在发布包根目录创建隔离环境后运行；已有环境可跳过第一行：

python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-foam.txt --index-url https://pypi.tuna.tsinghua.edu.cn/simple
.\.venv\Scripts\python.exe scripts/foam_model.py run --task examples/foam-refinement-demo/task.json --out outputs/foam-demo-1

打开新输出目录中的 report.md 阅读中文诊断；model.json、result.json 与输入快照保留计算依据。重复运行请换一个新目录。
