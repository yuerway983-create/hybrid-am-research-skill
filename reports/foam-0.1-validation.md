## 已实现

发泡 FDM 的两级密度换算、单尺度有界幂律标定、分级模量或初始屈服强度计算；原模型、普通密度残差修正和预声明宿主修正的条件分组比较；独立的温度／出料倍率到内部密度响应面；受支持范围内敏感性；输入快照、模型、结果及代码／输入哈希。

LLM 宿主整理文献与选择候选机理，数值脚本负责计算。脚本没有调用 LLM API、商业仿真软件或硬件。旧 VPP–DIW 的运行时、注册表和 14 工具接口没有新增泡沫工艺。主 Skill 的宿主路由和中文启动说明已补充；原有兼容性说明移到合法的 `metadata` 下，不改变旧数值工具实现。

## 合成案例

命令从完整仓库根目录运行：

```text
python scripts/foam_model.py run --task examples/foam-refinement-demo/task.json --out outputs/foam-demo-20261011-reviewed
```

输入 232 条原始记录，合并为 116 个合成样品；共有 58 个条件，训练与留出条件及批次标识分开。输出为 `synthetic_calculation_complete`，冻结选择 `host_proposed_refinement`。

| 模型 | 训练条件 CV RMSE（MPa） | 留出 RMSE（MPa） |
| --- | ---: | ---: |
| 原始两级模型 | 23.9674 | 19.9391 |
| 普通密度残差修正 | 2.65915 | 1.66483 |
| 预声明夹具修正 | 1.00158 | 0.858511 |

工艺到内部密度的 CV RMSE 为约 `2.18763e-6`，留出 RMSE 约 `9.37282e-7`，均无量纲。两部分单独完成数值检查，不构成温度／出料倍率到性能的端到端验证。

合成数据刻意含已知的孔隙份额交互修正，候选来源是 `synthetic_fixture`，不是 LLM 从真实数据发现的新机制。上述误差不能证明商用 LW-PLA 性能、实际实验优化或 LLM 优于普通建模。夹具公式与真值见示例目录说明及生成器。

## 独立宿主前向检查

独立代理读取新 Skill、必要引用、原始 task/CSV 后实际调用 CLI，未读取夹具生成器或示例真值说明。可完成限定目标的计算和解释，并指出 250°C 超过该演示 200–220°C 训练范围，不能据此给出范围外最优参数或吸能预测。

独立复核还把留出响应放大 100 倍：冻结模型选择与 `selection_sha256` 不变，数值关口变为失败，不会根据留出结果换模型。非法标识、非有限数据、越界密度／份额、技术重复不一致、路径越界和任意表达式候选均被拒绝。该前向检查是宿主使用行为的软件检查，不是付费 API 性能评测，也不是材料实物实验。

审查发现并修复了单尺度标定向分级模型转移时的域漏检。把宏观标定密度收窄至 `[0.47, 0.53]`、而分级宏观密度仍为 `[0.35, 0.75]` 时，原单尺度自身留出检查可以通过；新 `hierarchical_within_monoscale_calibration_domain` 则失败，使总体数值关口失败，同时保留诊断预测和逐样品域记录。回归测试也覆盖微观一级的同类反例。最终代码和输出代码哈希一致，`foam_model.py` 的 SHA-256 为 `6614c17d2d8a73faeb6c858ad4c9537f230b71fbf0a7c077f575ff44cc51a719`。
