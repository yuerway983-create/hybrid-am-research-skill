# foam-0.1 优化与发布前验证

日期：2026-10-11。此记录描述本轮软件优化，与[初版验证](foam-0.1-validation.md)分开。远端基线为 `9308e6a932f446451fdd2b9fa884c66be34e4316`；是否已上传以 Git 提交记录及分支状态为准。

## 本轮优化

- 中文报告从单一跨度扩展为有限扫描方向、真实支持范围、支持点数、两端预测及固定参考。方向区分上升、下降、非单调与数值精度内近似不变；不能将其当作因果、统计显著性或最优设备参数。
- 敏感性情景同时核对分级密度／孔隙份额凸包、微／宏单尺度标定密度范围和所选修正特征边际边界。没有两个不同支持点时明确不可用，不再把单点比较写成零效应。新增对合法致密训练点的保护：跳过生成的无效情景，不放松真实测量校验。
- 增加 `decision_summary`，分别列出力学、工艺密度和尺度审核状态，保留失败检查及中文优先补充事项。数值关口通过仍是候选，`physical_improvement_confirmed=false`。
- 先复制任务和 CSV，再从输出快照计算并哈希。运行中原始文件的后续变化不混入当前计算；失败可能保留已复制输入，但不生成成功模型。
- 提供 `templates/foam-research/` 中真实任务与 CSV 字段模板。未知参考性能、边界、门槛和机理项保持空值，模板故意不能直接通过校验。
- README 补充隔离安装、国内镜像、真实模板和验证记录入口；子 Skill 保持独立宿主调用。原 VPP–DIW 14 工具接口不变。
- 修复旧运行时的 Windows 相对路径键与 UTF-8 报告读取；静态 HTML 测试也显式按其实际 UTF-8 编码读取。历史报告未被覆盖，旧会话仍应遵循代码哈希约束。

## 验证环境与结果

Python 3.12.14；本轮在仓库外的隔离依赖目录使用 `requirements-foam.txt` 指定的 NumPy 2.3.5、SciPy 1.17.0。旧流程测试另外使用已安装的 scikit-learn 1.8.0 及其辅助依赖，不改变全局 Python 环境。

- 泡沫模块 73 项测试全部通过；比初版 59 项增加 14 项行为回归。
- 完整套件 347 项全部通过，耗时约 27.7 秒。使用 `-X utf8=0` 在 Windows 默认编码模式下验证，而非依赖全局 UTF-8 开关绕过旧问题。
- 主 Skill 与新子 Skill 均通过 `skill-creator` 格式校验；文档链接与 `git diff --check` 通过。
- 独立科学复核用窄单尺度密度域、非线性交互特征域、单点／窄工艺凸包和合法致密点反例检验了情景支持行为，无剩余阻塞项。
- 新增快照测试：计算后修改原任务／CSV，结果仍对应输出快照，输入哈希与快照一致。模板缺少真实参数时按预期阻塞。

复验命令（使用已安装依赖的 Python，从仓库根目录）：

```text
python -X utf8=0 -m unittest discover -s tests
python scripts/foam_model.py run --task examples/foam-refinement-demo/task.json --out outputs/foam-optimized-20261011-2
```

以上输出目录是此次新建目录，不应覆盖重跑；复验时换成不存在的新目录。`foam_model.py` SHA-256 为 `1b5d3a447b1467ae5bf5b65b7bd8d4c7a8006cd24718c8ab0a43f61d54bc596f`，合成运行的代码哈希已核对一致。

## 合成结果与边界

仍为 232 条原始记录、116 个合成样品、58 个条件。冻结模型选择未改变；原模型、普通修正与预声明夹具修正的分级留出 RMSE 分别约 19.9391、1.66483、0.858511 MPa。力学及工艺密度数值关口通过，尺度假设仍待审核。

演示显示总相对密度增大时模量上升，固定总密度时微观孔隙份额增大对应模量下降；温度增大对应内部密度下降，出料倍率增大对应内部密度上升。这些仅是该合成模型的有限支持扫描趋势，不能迁移成商用 LW-PLA 的工艺结论。

未执行真实打印或压缩实验，未调用付费 LLM API、商业仿真软件或设备。没有端到端工艺到性能验证、预测不确定性、吸能曲线、寿命模型或自动实验规划。修正项在夹具中被刻意预设，本记录不证明 LLM 优于普通建模。
