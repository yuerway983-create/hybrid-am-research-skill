**2026-10-01｜本地交付｜没有真实实验数据｜未创建远程GitHub仓库。**

## 这版完成的范围

保留之前已经实现的文献证据检查、两种观测量的标定、分组验证、候选参数规划和回传对照。
新增冻结重拟合、独立确认、数值验收、版本保留和下一轮衔接。至此，约定范围内的本地软件闭环完整。
科研流程仍是目标/数据→文献→轻量模型→虚拟试验→候选实验→外部结果→比较/更新。
执行层仍是主控每个阶段先选择并激活已审核Skill，再调用真实Python工具并检查返回。

**没有把真实数据缺失作为停工理由；也没有用合成数值替代真实实验结论。**

## 本版新增

| 功能 | 实际实现 |
|---|---|
| refit_update | 原模型先评分后，新建候选模型，只用update中的fit数据；参数/门槛保持原声明 |
| confirmation_plan | 在读到新确认结果前生成覆盖条件；额外确认试验成本单独声明 |
| attach-confirmation | 操作者附加新数据，核对候选哈希、方案哈希、观测量、来源和整个历史的样品/批次 |
| evaluate_update | 只评分已冻结候选；检查CV、独立组、域内、正值、误差和不退化条件 |
| start_next_round | 通过则继承模型创建新会话；失败/无确认则只创建标定规划，不硬给预测 |
| attach-evidence | 补入宿主实际检索整理的证据包；不把本地导入说成联网检索 |
| 多轮状态 | 轮次、最大轮数、父子会话、已用数据身份、模型与结果历史均保留 |
| 使用入口 | 主SKILL、宿主说明、空模板、独立演示、静态概览和回归测试 |

主控工具共14个；附加文献、实验、确认以及生成合成测试数据都不作为LLM执行权限。

## 实际验收

1. **274项单元/回归测试通过**，包含之前213项及本轮新增61项。
2. **8项SymPy符号检查通过**，只验证数学关系而非真实材料。
3. 正常合成环境：第一轮→回传→重拟合→独立确认→第二轮；再重复更新→第三轮建议。
4. 偏移合成环境：更新检查失败，第二轮自动转为标定/覆盖方案，预测留空。
5. 数据不足分支、没有确认的分支、复用旧样品/批次、错观测量、越界、篡改、重复调用、超轮次预算等均测试。
6. 可选Responses传输用明确mock测试了跨轮会话切换；没有使用用户API密钥或真实付费API。
7. 本轮聊天宿主实际逐次执行**29次工具调用**：第一轮24次，第二轮5次，审计哈希链均通过。
   这份运行不是调用campaign_demo固定脚本；合成回传与确认由独立的测试操作步骤附加。

正常样例有意使用与基准模型兼容的人工响应函数，目的是测试流程。其小误差不证明真实材料预测精度。
偏移样例用于测试模型失效分支；任何数值好坏均不能用于宣称打印成品性能改进。

## 数据使用纪律

旧模型必须先评分，随后才能把新结果用作开发数据。旧holdout退役，不能再当下一轮新测试。
候选重拟合后冻结，再由操作者附加确认数据。新确认通过后可用于模型验收，但已被使用，
不能再次当作独立最终评估。模型/阈值不因失败自动改变。旧模型和负结果不覆盖。
实际实验中，确认数据还需要独立采集；ID检查不能证明来源真实性。
没有点位置信区间、p值、样本量功效或无限次顺序检验结论。

## 三种运行方式

- **离线软件测试**：campaign_demo，现已验收。无需真实数据/API。
- **文件/终端宿主LLM**：逐条选择工具，本轮实际验收至第二轮候选输出。
- **独立API宿主**：代码与mock协议测试已具备，但用户选择模型、配置凭据后的外部部署仍需联机验收。

新文献和从未见过的GitHub技能仍由授权宿主实时检索、审核后导入/接入。
find_skills是已审核清单查询，不是GitHub全网搜索；没有开放无人安装任意网上代码。

## 保留的边界不是未接完的软件步骤

不承诺任意材料/工艺通用。界面性能、图像测量、多目标BO、逐点预测区间和完整GUI不在本版范围内。
真实材料标定、打印、性能与统计确认留待取得真实数据后检验，不用软件示例冒充。
