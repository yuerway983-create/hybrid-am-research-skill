## 原文真正支持什么

Jin等的Small论文（2023，10.1002/smll.202302405）2.1节公式(1)–(3)
采用一维Fick扩散并给出 `sigma^2=2Dt`。sigma是浓度分布的空间标准差，
不等于照片中可见轨迹的几何宽度。论文提到的补充图S5测量映射本次未取得，
未数字化图中曲线，也未获得可直接用于本项目的材料标定系数。

因此第一个模型使用显式标注的有限初始高斯宽度扩展：

`sigma(t)^2 = sigma0^2 + 2*D*t`

该扩展由本项目推导、核查，不写成论文原公式。速度、压力、喷嘴等条件固定；
当前只有一个时间方向的计算子模块，不假装已完成“速度＋延迟→实际宽度”的优化。

光固化工作曲线作为后续候选保存。Kolibaba等（2024，10.1016/j.addma.2024.104082）
的相关正文支持区分曝光能量与时间、材料标定及模型范围；本版不实现固化深度预测。
Bennett 2017只读到NIST摘要，明确保存为摘要层级。用户提供的LLM-3D Print
仅作为流程调度的参考，不为本项目提供材料数据。

## 当前计算输出

给定带单位和来源的初始标准差、扩散系数、时间与范围，输出浓度方差、标准差和
高斯半高全宽。可选D上下界仅生成参数情景包络，不是带覆盖概率的置信区间。
示例的50 um、40 um2/s等值完全是测试夹具，不是实验结论、设备建议或文献标定值。

8项数学检查包括：扩散方程残差、归一化总量、中心、二阶矩、初始条件、线源极限、
方差增长和量纲一致。它们不验证真实材料是否服从该模型。

## 怎样运行

```text
python scripts/stage2_demo.py --out runs/demo-02
python -m unittest discover -s tests -v
```

有SymPy时可另外运行：

```text
python scripts/verify_diffusion_symbolic.py --out runs/symbolic-02.json
```

数值与证据回放不需额外依赖或API密钥。输出目录必须是新的。
下载后的演示读取已冻结证据，不重新联网。聊天宿主的实际研究过程和下载脚本的
离线回放，在记录中分别标注。
