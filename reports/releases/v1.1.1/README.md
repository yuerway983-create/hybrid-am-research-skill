# Axiom Research · v1.1.1 页面与研究入口更新

首页和 GitHub README 现聚焦 Reece Oosterbeek 团队相关的发泡 FDM 分级聚合物泡沫研究：LLM 辅助因素提取、两级简化计算、模型标定与有限修正。原论文与牛津研究主页已在页面中关联，项目扩展与原研究方法分别说明。

## 本版变化

- 首页主标题、研究介绍、能力卡片、流程、模板和运行命令改为泡沫研究内容。
- 快速开始、LLM 宿主入口及主 Skill 介绍首先指向独立泡沫模块。
- 旧 VPP–DIW 14 工具流程与报告集中到 `LEGACY_VPP_DIW.md`，历史内容不改写为泡沫结果。
- 更新完整下载包、版本信息与文件校验清单。

发布包为 **1.1.1**；泡沫模块仍为 **foam-0.1**，旧 VPP–DIW 运行时为 **1.0.0**，原因分析为 **0.2.0**。本版只修改介绍、入口与发布内容，不改变数值计算、输入契约或验收门槛。

完整 ZIP 根目录为 `axiom-research/`。根 `MANIFEST.json` 记录包内文件 SHA-256（自身除外），旧 v1.1.0 清单另存于 `reports/releases/v1.1.0/MANIFEST.json`；发布附件 `SHA256SUMS.txt` 用于验证整个 ZIP。旧发布继续作为历史版本保留。

## 验证与研究边界

发布检查包括本地文档链接、Skill 格式、页面窄屏／桌面呈现、解压包完整性与首页给出的泡沫演示入口。数值实现未变，已有 73 项泡沫测试与 347 项完整测试记录见 `reports/foam-0.1-optimization-validation.md`。

演示使用合成数据，不能证明真实材料性能或 LLM 优势。当前没有自动泡沫实验规划、端到端工艺到性能验证、完整吸能曲线、疲劳／降解寿命或实物改善确认。项目围绕公开研究构建，不是牛津大学或 Reece 团队的官方软件。
