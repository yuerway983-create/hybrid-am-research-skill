# Axiom Research · v1.1.2 科研建模与实验优化工具包

本版将页面、Skill 说明、能力目录和完整下载包统一为通用功能介绍，方便面向不同研究方向展示。

## 命名与内容

- 完整包：`axiom-research-modeling-toolkit-v1.1.2.zip`，中文名称为“科研建模与实验优化工具包”。
- 模块按能力命名：科研证据整理与核查、测量响应标定与验证、扩散特征计算、约束实验规划、标定实验规划、实验反馈与模型比较、模型更新与迭代验证、原因分析与参数建议、分级泡沫建模与修正。
- 当前介绍、示例提示词和泡沫来源说明去除个人定向表述及个人主页；论文方法保留标题、DOI 与原文位置，便于核查。
- 模块调用标识与目录保持兼容，具体适用材料、工艺、观测量和验证边界保持原定义。

模块均随完整工具包交付，并非可任意拆开的独立安装包。泡沫计算仍为 `foam-0.1` 独立入口；旧 VPP–DIW 运行时为 `1.0.0`，原因分析为 `0.2.0`。通用名称不意味着增加了新材料模型或自动泡沫闭环。

## 下载与核验

解压后的根目录是 `axiom-research/`。根 `MANIFEST.json` 记录本版文件 SHA-256（自身除外），发布附件 `SHA256SUMS.txt` 用于核对 ZIP。旧版清单只用于对应旧版，不应用于本版中已更新介绍的文件。

之前带有个人定向介绍的发布包转为归档，公开下载统一使用本版。原 Git 标签和已有实验／审计快照保留，避免把历史证据改写为新的研究结果。

本版不改变数值脚本、数据契约或实验门槛。合成演示仅验证软件行为；没有新增真实实验、完整仿真、设备控制或已确认材料性能提升。
