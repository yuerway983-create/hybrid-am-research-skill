# Axiom Research · v1.1.0 发布说明

本次发布将线上仓库名称、主 Skill 名称与完整下载包统一为 Axiom Research。它补发主分支已有更新，不新增尚未实现的候选预测、自动泡沫实验规划或端到端工艺性能仿真。

## 包含内容

- 主 Skill `axiom-research` 与界面展示信息。
- 原 VPP–DIW v1.0 运行时、已审核子 Skill、示例和模板。
- 原因分析子 Skill v0.2.0 与结构化输出约定。
- 独立发泡 FDM 分级聚合物模块 foam-0.1、简化计算脚本及真实研究模板。
- 完整测试与历史验证记录；历史报告保持原始版本标题，不重写实验结论。

完整 ZIP 的根目录为 `axiom-research/`，与主 Skill 标识一致。根 `MANIFEST.json` 记录当前包内文件的 SHA-256（清单自身除外）；旧 v1.0.0 清单保留于 `reports/releases/v1.0.0/MANIFEST.json`，不应拿它验证当前包。ZIP 的校验值另见发布附件 `SHA256SUMS.txt`。

下载包不包括 `.git/`、虚拟环境、依赖缓存、凭据、私有数据或本地输出。依赖需按所使用的模块安装；模型参数、设备边界和真实测量不得由演示常数代替。

本次仅修正发布、名称与新生成报告的展示。VPP–DIW 数值模型、泡沫数值模型及现有科学验收门槛不变；已有会话如涉及变更后的代码哈希，应按原规则新建会话，不绕过一致性检查。

## 验证边界

软件测试和合成示例不是实际打印、材料改善或 LLM 优势的证明。没有执行付费 LLM API、商业求解器或设备命令。原因分析仍是宿主补充步骤，泡沫模块仍走独立数值入口；完整包不会把它们误标为已接入旧 14 工具状态机。
