## 本轮主控的实际行为

先看到几何宽度而非浓度sigma，因此选经验宽度标定；预定数值检查通过后，
选择有界目标候选＋覆盖＋基准，不选择标定-only或未集成的pymoo。
没有新数据时先生成等待报告。随后开发演示明确附加了合成回传夹具，
主控选择回传对照工具，读取结果发现候选表现变差，于是保留负结果并准备新标定数据。

实际回传：36条合成技术测量 → 18个合成样品 → 3个批次。
识别1个实际参数偏离计划的样品，保留记录但不计入目标方案效果。
目标500 μm的合成案例中，基准平均绝对误差约2.701 μm，目标候选约3.993 μm。
程序输出descriptive_worsening。两个条件均可能满足较宽的容许误差，但“达标”不等于“比基准更好”。
以上数字仅验证软件不会把负结果说成优化成功，不是任何真实树脂、设备或成品的实验结论。

## 使用

```text

python scripts/stage4_demo.py --out runs/demo-04
python -m unittest discover -s tests -v
```

本地固定演示不是AI智能体。要让LLM逐步决策，读HOST_START.md，通过agent_bridge.py调用。
当前宿主真实记录在reports/host-session-001，静态总览在reports/STAGE4_OVERVIEW.html。
