# 第一个轻量模型：依据、选择和边界

## 当前决策

先做固定材料与沉积条件下的浓度分布扩散矩计算，不直接做“速度＋固化延迟→几何宽度”的二维预测。
该计算是完整研究流程中的第一个子工具，不是把最终研究目标缩成单一公式。

## 原文依据与项目推导必须分开

**S1：Jin等，Small，2023，10.1002/smll.202302405，2.1节公式(1)–(3)。**
论文用一维Fick扩散描述沉积材料在树脂基体中的扩散，并给出空间方差关系 `sigma^2=2Dt`。
sigma描述浓度峰的空间分布。该文指向补充图S5说明测量方法；本次补充材料无法取得，
也未成功取得图像截图，因此没有数字化曲线或核实几何测量至sigma的转换。
原文：https://onlinelibrary.wiley.com/doi/full/10.1002/smll.202302405

**C2：本项目的显式数学扩展，不是论文直接给出的新公式。**
在无界一维、恒定D、无对流、未进入凝胶约束、初始分布为高斯的条件下：

`V(t) = sigma0^2 + 2Dt`

`c(x,t) = exp(-x^2/(2V)) / sqrt(2*pi*V)` （归一化、中心平移为0）

程序验证扩散方程残差为0、总量为1、均值保持、二阶矩、初始条件、线源极限、
方差增长率和量纲关系。数学正确并不证明混合打印材料确实满足上述假设。

## 为什么先不做另外两个模型

| 候选 | 当前处理 | 缺口 |
|---|---|---|
| 一维扩散矩 | 已实现形式和合成演示 | 材料D、初始剖面、有效时间范围与观测定义 |
| 几何宽度经验预测 | 下一步候选，不在v0.2里训练 | 同材料同条件的匹配测量数据、独立样本、速度范围 |
| 光固化工作曲线 | 文献中核查了形式，暂未实现 | 材料/波长的Dp、Ec，真实辐射曝光量和适用范围 |

S3的工作曲线用 `Cd=Dp*ln(E0/Ec)`；E0是单位面积能量，不是激光功率、PWM比例或沉积延迟。
来源：Kolibaba等，2024，10.1016/j.addma.2024.104082，Introduction Eq.(1)及相关讨论，
https://pmc.ncbi.nlm.nih.gov/articles/PMC10986335/ 。该处已读取相关文本；后续重开曾返回浏览器校验。
Bennett 2017的NIST摘要只作为材料标定背景，不作为逐个参数或公式已读全文的依据。

## 本工具的输出与非输出

输出：给定参数下的浓度方差、标准差和高斯半高全宽；给定D情景范围时输出相应包络。
包络不是置信区间，未包含模型误差、观测误差和未提供的测量不确定性。

不输出：几何轨迹宽度、固化程度、界面强度、疲劳寿命、堵头概率或最佳设备参数。
不把任意系数写成材料参数，不把文献条件的一个值作为当前设备允许范围。

## 真实模式需要什么

材料对/批次、固定速度/压力/喷嘴/温度、实际时间戳、剖面定义及比例尺，
足以估计初始方差和D的独立数据、预先声明的适用区间、留出验证和不确定性。
所需延迟级数与重复数要按参数可识别性和噪声规划，这里不宣称固定三组足够。

目前真实模板留空，程序应拒绝计算。以后只得到几何宽度时，可另建经验模型；
除非独立验证对应关系，否则不能把其拟合系数称为分子扩散系数。

## 接入研究闭环

文献与输入检查 → 选择模型 → 数据足够才计算 → 结果/范围检查 → 后续候选试验设计。
如果缺数据：返回标定需求，不让优化器从不存在的真实响应中找到“最优参数”。
