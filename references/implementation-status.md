# v1.0 implementation status

Completed: the bounded local pre-experiment + feedback + refit + confirmation + next-round loop.
Implemented interfaces: 14 model-callable tools; operator-only evidence/feedback/confirmation attachments;
versioned session state, skill activations, input/code/artifact hashes, child-round handoff and audit.

Scientific routes: concentration sigma diffusion calibration OR empirical two-factor geometric-width model.
No automatic equivalence between observables; no inferred strength/fatigue/cure response without a model.
The local evidence tool checks a frozen/host-attached packet. Live literature and new GitHub skill discovery
are the authorised host's responsibility; no unattended remote-code installer is included.

Validation: unit/regression tests + deterministic synthetic multi-round campaign + labelled host tool calls.
The optional Responses transport is only contract-tested with mocks; a live account is deployment-specific.
Synthetic confirmation is supplied by separate test/operator code, never by a model-callable tool.
All examples remain synthetic; no real material, fabrication or physical-performance result is established.

Intentional scope exclusions: printer control, dedicated simulation software, unlimited new-code execution,
image metrology, calibrated pointwise intervals, formal hypothesis/power calculations and multi-objective BO.
These are not prerequisites for the agreed software prototype and are not claimed complete.
